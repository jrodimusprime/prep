# prep

Audio study player for an EM interview: SQL Server DBAs moving to AWS.

112 questions, each with what a strong answer covers, read aloud in about 28 minutes.

**Listen:** https://jrodimusprime.github.io/prep/

- Section skips, 15-second jumps and speeds from 1× to 1.75×
- Remembers your place and speed on each device
- Lock-screen controls on phones; keeps playing with the screen off
- Full question list with "Listen for" notes under each section

To listen with the browser fully closed, download `EM-Interview-Prep-SQL-Server-to-AWS.mp3` and play it from your files or a podcast app.
